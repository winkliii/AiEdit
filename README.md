# OrbanPhoto – kituri de instalare

Kituri complete pentru pluginul OrbanPhoto (Lightroom Classic). Se instalează **fără internet**.

## Descarcă ultima versiune

Linkurile de mai jos rămân aceleași la fiecare versiune nouă – duc mereu la ultima.

- Pagina ultimei versiuni: https://github.com/winkliii/AiEdit/releases/latest
- **Windows – instalator:** https://github.com/winkliii/AiEdit/releases/latest/download/OrbanPhoto-Windows.exe
- **Mac – kit:** https://github.com/winkliii/AiEdit/releases/latest/download/OrbanPhoto-Mac.zip
- Windows – kit (arhivă): https://github.com/winkliii/AiEdit/releases/latest/download/OrbanPhoto-Windows.zip

Versiunea anterioară: [toate versiunile](https://github.com/winkliii/AiEdit/releases) (a doua de sus).

Ultima versiune: **v48.34** ([toate versiunile](../../releases))

**Mac:** dezarhivează, apoi clic dreapta pe „Instalează OrbanPhoto.command” › Deschide › Deschide.

**Windows:** clic dreapta pe arhivă › Extrage tot…, apoi dublu-clic pe „Instaleaza OrbanPhoto.bat”. Dacă apare „Windows a protejat computerul”: Mai multe informații › Rulează oricum.

Kiturile nu conțin nimic învățat: fiecare calculator învață stilul din catalog, sau îl importă dintr-un fișier `.orbanstyle` (aplicația OrbanPhoto › „Importă stil…”).
