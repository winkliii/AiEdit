# OrbanPhoto – kituri de instalare

Kituri complete pentru pluginul OrbanPhoto (Lightroom Classic). Se instalează **fără internet**.

Descarcă din **[Releases](../../releases/latest)**:

| Fișier | Pentru |
|---|---|
| `OrbanPhoto-Mac-offline-*.zip` | Mac cu Apple Silicon (M1 sau mai nou), macOS 15+ |
| `OrbanPhoto-Windows-offline-*.zip` | Windows 10/11, 64 de biți |

**Mac:** dezarhivează, apoi clic dreapta pe „Instalează OrbanPhoto.command” › Deschide › Deschide.

**Windows:** clic dreapta pe arhivă › Extrage tot…, apoi dublu-clic pe „Instaleaza OrbanPhoto.bat”. Dacă apare „Windows a protejat computerul”: Mai multe informații › Rulează oricum.

Kiturile nu conțin nimic învățat: fiecare calculator învață stilul din catalog, sau îl importă dintr-un fișier `.orbanstyle` (aplicația OrbanPhoto › „Importă stil…”).
